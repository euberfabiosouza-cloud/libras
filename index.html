Sincronizar entre aparelhos

1. Vá em github.com/settings/tokens → "Generate new token" → Tokens (classic).
2. Marque só a caixinha gist (nada mais) e gere o token.
3. Cole o token aqui e clique em "Conectar" — no primeiro aparelho, deixe o ID do Gist em branco pra criar um novo.
4. No segundo aparelho, cole o mesmo token (ou outro seu, também com escopo "gist") e o ID do Gist que apareceu no passo anterior.
O token fica salvo só neste navegador — nunca é enviado a mais ninguém além do próprio GitHub.
